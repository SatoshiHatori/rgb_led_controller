# ADR-0005: CAN の色指定フレーム

状態: 採用 (2026-11-07)。ロボット側の CAN 仕様とは未照合。

## 決定

- 500kbit/s、11bit 標準 ID `0x7D0`。`CAN_BRP` と `CAN_COLOR_ID` でビルド時に変更できる。
- 表示はロボットの制御より重要でないので、低優先の ID にする。CAN は番号が大きいほど低優先。0x7F0 以上は古い CAN 規格で禁止されていた範囲なので避ける。
- data[0..2] = R, G, B (0〜255)。2 乗カーブで PWM デューティに変換する。
- data[3] = 点灯時間 × 100ms (最大 25.5 秒)。過ぎると消灯する。0 または省略で 500ms (`COLOR_TIMEOUT_MS`)。受信のたびに時間を更新する。
- DLC が 3 未満のフレームは無視する。

## 結果

- バス負荷が高いと色指定フレームは後回しになる。遅れが消灯時間 500ms を超えると、一時的に消灯する。
- CAN が途絶えると必ず消灯する。移動ロボットで、古い状態を表示し続けないようにするため。
- 点灯を続けるには、送信側が 500ms より短い周期で送り続ける必要がある。
- 意図的に長く点灯させたい場合は data[3] を指定する。その場合、途絶から消灯まで最大 25.5 秒かかる。
