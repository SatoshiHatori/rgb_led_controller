# ADR-0002: LED 駆動は 5V ゲートの TPH4R10ANL にする

状態: FET の型番は ADR-0007 で HYG080N10LS1C2 に置換 (2026-11-07)。5V ゲート駆動の構成は継続。

## 背景

3.3V の GPIO では 100V 定格の FET を十分に ON できない。一方で専用ゲートドライバは単価が上がる。

## 決定

Q2〜Q4 に TPH4R10ANL (100V、VGS 4.5V で最大 6.6mΩ、SOP Advance) を使う。ゲートは TC74VHCT04 を 2 段直列にした非反転バッファから 5V で駆動し、直列に R10〜R12 (470Ω) を入れる。プルダウン R7〜R9、R13〜R15 で起動中は消灯する。

## 結果

- 5A 時の導通損は最大 0.17W (25°C)。
- ゲート電流が約 10mA に制限され、スイッチングに約 3.7µs (Qg 37nC) かかる。24V 5A の損失見積りは 1kHz で 0.44W。PWM は 1kHz とし、2kHz を超えないようにする。
- U3 の入力が 3.3V で動くよう、TTL しきい値の VHCT を使う。
- 秋月の TPH4R10ANL は在庫僅少だった。JLCPCB で実装するため、ADR-0007 で LCSC 品に替えた。
