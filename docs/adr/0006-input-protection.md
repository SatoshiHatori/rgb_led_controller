# ADR-0006: 入力保護は 45V 耐圧の TVS にする

状態: 採用 (2026-11-07)。ADR 初版の 58V 級から変更。

## 背景

当初は 24V 車両を想定してロードダンプ対策を入れた。その後、用途は移動ロボットで、この基板の電源はモータ駆動回路とは別系統で、DC/DC コンバータの 24V 出力と判明した。モータの回生は直接入らない。

## 決定

- TVS を SMBJ58CA から SMBJ45CA (耐圧 45V、クランプ最大 72.7V、双方向、SMB) に変更する。同じパッケージなので配線は変えない。
- ローサイド逆接保護 Q1、ヒューズ 10A、100V 定格の FET、高電圧ネットのクリアランス 0.6mm は維持する。ホットプラグのサージと逆接は別電源でも起こる。

## 結果

- 秋月で購入でき、Digi-Key の発注が不要になる。
- クランプ電圧が 93.6V から 72.7V に下がり、100V 定格の部品の余裕が増える。
- 回路の入力上限は約 45V で、24V 出力に対して十分な余裕がある。
- 秋月品のピーク電力は商品ページで 400W の表記で、Littelfuse の 600W 品より小さい。別電源なので許容した。
- TVS 以外の部品は変えていない。FET などは秋月での入手性と価格で選んでおり、定格を下げても安くなる見込みが小さいため。
- その後 ADR-0007 で FET とヒューズを LCSC 品に替えた。100V の FET を選んだので、TVS とクリアランスはこの ADR のまま。ヒューズは 0451010.MRL (10A、125V)。
