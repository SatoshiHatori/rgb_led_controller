# ADR-0001: マイコンを CH32V203K8T6 に置き換える

状態: 採用 (2026-11-07)

## 背景

XIAO RA4M1 は単体で約 ¥1,540 と高く、基板も大きくなる。必要な機能は CAN 受信と PWM 3 チャンネルのみ。

## 決定

CH32V203K8T6 (秋月 調査時 ¥120) と CAN トランシーバ ATA6561 (同 ¥80) を基板に直接実装する。クロックは 8MHz 水晶を PLL なしで使う。

## 結果

- 部品代の大半を占めていたマイコン代が下がる。
- 書き込みに WCH-LinkE と J4 (1.27mm パッド、未実装) が必要になる。
- USB からの開発はできなくなる。
- XIAO 版 (Rev A) はこの決定を受けて削除した。
