# ADR-0007: JLCPCB で部品実装まで行い、部品を LCSC 品にする

状態: 採用 (2026-11-07)。ADR-0002 の FET、ADR-0003 の Q5、REQ-011 (秋月で購入) を置き換える。

## 背景

- 基板は JLCPCB に部品実装まで頼み、5 枚程度作る。
- JLCPCB の実装では、LCSC (JLC の部品在庫) の部品しか使えない。
- 秋月の TPH4R10ANL は通販在庫が 5 個で、1 枚分 (4 個) しかなかった。
- 実装費は拡張部品 1 種類ごとに $3.07 かかる。基本部品 (Basic) と優先部品 (Preferred) はかからない。

## 決定

| 部品 | 旧 (秋月) | 新 (LCSC) | 理由 |
|---|---|---|---|
| Q1〜Q4 | TPH4R10ANL | HUAYI HYG080N10LS1C2 (C3011225) | 100V、VGS 4.5V で最大 13mΩ、在庫約 14,700 個。ピン配置が同じで TVS も変えずに済む |
| F1 | Keystone 3557-15 + 0891010.NXS | Littelfuse 0451010.MRL (C44479、2410 SMD、10A 125V、速断) | ホルダは JLC に在庫がない。表面実装にして全数を実装できる |
| Q5 | 2SK2623 | Infineon IRFR3910 (C148158、100V、VGS ±20V) | 2SK2623 は在庫なし。IRLR3410 は VGS が ±16V で 15V ツェナーに対し余裕が小さい |
| D2, D3 | UDZV15B | BZT52C15S (C173448、SOD-323) | UDZV15B は在庫なし |
| U3 | TC74VHCT04AFT | 74VHCT04AFT (C5381636) | 同等品 |
| U4 | NJM78L05SU3 | CJ78L05 (C2079、SOT-89、0.6W) | ピン配置 OUT-GND-IN が同じ。基本部品の UTC 78L05G-AB3-R は SOT-89 で 350mW のため不採用 (下記) |
| Y1 | 8M10PB | YXC TAXM8M4RDBCCT2T (C400090、10pF) | 負荷容量 10pF が同じ。基本部品の 8MHz は 20pF でサイズも違う |
| 抵抗、C3〜C14 | 秋月品 | 基本部品 | 実装の追加料金がかからない |
| J1〜J3 | JST 純正 | JST 純正 (LCSC) | 同じ型番。互換品 XY-B4P-VH は定格 3A のため不採用 |

- フットプリント: Q1〜Q4 は `vsi:PDFN-8_5x6mm_P1.27mm` (HUAYI のパッケージ図に合わせ、ドレインパッドを 0.25mm 延長)。F1 は `vsi:Fuse_Littelfuse_NANO2_2410` (データシートの推奨ランド)。
- JLCPCB 向けに、シルク文字を 1.0mm に、J4 のパッドを 1.05mm (環状幅 0.2mm) に変更した。
- 実装は Economic PCBA (片面)。J1〜J3 は挿入部品として JLC の手はんだで付ける。
- 電線側のハウジングとコンタクトは引き続き秋月で買う (`harness_parts.csv`)。

## 結果

- 5 枚分の見積りは約 $97 (部品 $31.9、拡張部品の追加料金 16 種類 $49.1、基本料など $15.8)。これに基板代と送料が加わる。
- 追加料金は枚数によらず 1 回の注文ごとにかかるので、枚数が多いほど 1 枚あたりが下がる。
- FET のオン抵抗は最大 6.6mΩ から 13mΩ に上がる。5A 時の導通損は 1 個あたり最大 0.33W (25°C)。ゲート電荷は 37nC から 15.8nC に下がり、スイッチング損は減る。
- Q5 の VGS(th) が 3.5〜5.5V から 2〜4V に下がり、VPRE が約 9〜11V から約 9.5〜13.3V に上がる。U4 の損失は 5V 系 60mA で最大約 0.5W になる。このため U4 は定格 0.6W の CJ78L05 にした。温度は実機で確認する。
- 秋月だけで買って手はんだする方法は取らない。必要なら ADR-0001〜0006 の秋月品に戻せるが、フットプリントは F1 と Q1〜Q4 で異なる。
- JLC の部品配置の回転は、KiCad の座標ファイルと合わないことがある。発注時に JLC のプレビューで確認する。
