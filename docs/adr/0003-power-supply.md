# ADR-0003: 電源は FET リニアプリレギュレータで作る

状態: 採用 (2026-11-07)。Q5 と U4 の型番は ADR-0007 で変更 (Q5 IRFR3910、U4 CJ78L05)。

## 背景

Rev A の 100V 降圧 IC (LM5164) はインダクタなどを含めて高価で面積も大きい。マイコンと CAN の消費電流は小さい。

## 決定

Q5 (2SK2623) のソースフォロワで約 9〜11V に落とし (VPRE)、NJM78L05 で 5V、AP7333 で 3.3V を作る。

## 結果

- 部品が減り、インダクタが不要になる。
- 入力電圧の下限が約 10V から約 13V に上がる (Q5 の VGS(th) 3.5〜5.5V による)。IRFR3910 (VGS(th) 2〜4V) では VPRE が約 9.5〜13.3V になり、下限は少し下がる (ADR-0007)。
- Q5 の損失が入力電圧に比例する。5V 系を 60mA とすると 24V で約 0.8W、29.4V で約 1.1W。熱は実機で確認する。
