# 要求一覧

RGB LED Controller の要求と現在の状態を管理する。最終更新: 2026-11-08

## 運用ルール

- 要求を追加するときは、次の空き番号で行を足す。番号は再利用しない。
- 取り下げた要求や置き換えた要求は消さず、状態を「置換」にして置換先を書く。
- 状態を「完了」にするのは、根拠欄に確認方法を書けるときだけにする。
- 設計上の前提 (`ASM-`) は、確認が取れたら「確認済」にする。要求に昇格する場合は `REQ-` を追加する。

| 状態 | 意味 |
|---|---|
| 完了 | 確認済み |
| 設計完了 | 図面と検証ツールで確認済み。実機は未確認 |
| 進行中 | 一部できているが、満たしていない |
| 置換 | 別の要求に置き換えた |
